Privacy Policy

This Privacy Policy explains how Flix handles data in the dashboard and Discord bot environment.

1. Information We May Store

To operate correctly, Flix may store limited server configuration data, including:

  • Discord server IDs
  • Channel IDs
  • Welcome message settings
  • Maintenance status and messages

2. Why We Store Data

We store this data so the bot can manage welcome flows, maintenance mode, and other server automation functions.

3. Data Protection

We take reasonable steps to protect server configuration data and limit access to authorized administrators.

4. Data Sharing

We do not sell or rent personal data. Data may be shared only with trusted operational tools required to run the bot.

5. Third-Party Services

Flix uses Discord APIs and related infrastructure. Your use is also subject to Discord’s privacy and platform rules.

6. Contact

If you have questions about this policy, contact the project owner through the repository or support channel.
